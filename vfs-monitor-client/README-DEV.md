# Монитор слотов VFS — настройка (для разработчика)

Разовая настройка на машине заказчика. Дальше заказчик кликает два ярлыка и
иногда входит в кабинет. Простая памятка для него —
[ИНСТРУКЦИЯ-ЗАКАЗЧИКУ.md](ИНСТРУКЦИЯ-ЗАКАЗЧИКУ.md).

## Как это работает

VFS закрыт антиботом (Cloudflare Turnstile + Akamai), поэтому автоматический
вход невозможен — его проходит человек. Дальше:

- человек **один раз входит** в настоящем Chrome (запущен с портом отладки);
- монитор **подключается к этому Chrome** и раз в несколько минут читает
  доступность тем же запросом, что делает сайт (`CheckIsSlotAvailable`);
- появилась дата — шлёт уведомление в Telegram;
- **сессия VFS живёт ~20–30 минут** (жёсткий серверный лимит, продлить нельзя).
  Когда она истекает, монитор через CDP приводит вкладку в предсказуемое
  состояние: **разворачивает окно (даже если свёрнуто), выводит его вперёд,
  открывает форму входа** (браузер обычно подставляет логин/пароль) и **ждёт,
  пока кнопка «Войти» станет активной** (поля заполнены, Turnstile пройден).
  Тогда шлёт в Telegram «🔑 нажми Войти». Нужно нажать «Войти» — и монитор сам
  продолжает. Если вход не сделан, напоминание повторяется каждые 5 минут
  (монитор не «залипает»).

Работает только на **постоянно включённом ПК** с настоящим Chrome и обычным
(не серверным) интернетом. В облаке/Railway не запускается.

## Что нужно заранее

- Windows-ПК заказчика, не уходящий в сон.
- **Google Chrome**.
- **Python 3.12+** (при установке отметить «Add Python to PATH»):
  https://www.python.org/downloads/
- **Аккаунт VFS заказчика** (логин/пароль вводит он сам).
- Эта папка `vfs-monitor-client` на его ПК.

## Настройка по шагам

1. **Окружение.** Двойной клик `setup.bat` (ставит `.venv` + playwright;
   браузеры playwright скачивать не нужно — цепляемся к Chrome).

2. **Новый бот.** У @BotFather: `/newbot` → получить **токен**. Заказчик
   пишет своему боту `/start` (иначе бот не сможет ему писать).

3. **chat_id.** Куда слать уведомления:
   - **в личку** — заказчик пишет @userinfobot, берёт число `Id`;
   - **в группу** (удобнее — видят все): создать группу, **добавить туда бота**,
     затем временно добавить @getidsbot (или @RawDataBot) — он покажет
     `Chat ID` группы, это **отрицательное** число (напр. `-1001234567890`);
     скопировать его, помощника-бота удалить. Бот должен **остаться** в группе.

4. **Конфиг.** Скопировать `monitor_config.example.json` →
   `monitor_config.json`, вписать `bot_token` и `chat_id`. Для группы `chat_id`
   — с минусом: `"chat_id": -1001234567890` (в JSON это число, без кавычек).

5. **Chrome.** Двойной клик `1-start-chrome.bat` → заказчик **входит сам**
   (email, пароль, Turnstile), доходит до кабинета. Окно не закрывать.

6. **Коды центра/категории.** Двойной клик `probe.bat`, пройти в том же
   Chrome «Записаться на приём» → его центр → категория → подкатегория.
   Скрипт напечатает `vacCode` и `visaCategoryCode`.

7. **Цель.** Вписать эти коды в `targets` файла `monitor_config.json`.

8. **Запуск.** Двойной клик `2-start-monitor.bat` → в Telegram придёт
   `✅ Монитор запущен`. Дальше молчит, пока слотов нет.

## Автоматизация входа (AHK) — твоя часть

Платформа под это **максимально подготовлена**: при истечении сессии монитор
через CDP разворачивает окно (даже свёрнутое), выводит его вперёд, открывает
форму входа и **ждёт, пока кнопка «Войти» станет активной** (поля заполнены,
Turnstile пройден). То есть автокликеру (или тебе) остаётся нажать по уже
готовой кнопке, а не угадывать момент. Сигнал — уведомление `🔑 нажми Войти`.

Саму реализацию нажатия «Войти» оставляю на тебя — в поставку монитора она не
входит. Если делаешь через AutoHotkey, надёжнее не по фиксированным
координатам, а искать кнопку динамически (UI Automation по имени кнопки либо
ImageSearch по картинке) и таргетить конкретное окно Chrome по заголовку
(`Вход | VFS Global`), а не «любое переднее».

Учти: Turnstile проходит сам не всегда, а частые автоматические входы на
визовом аккаунте могут привести к его блокировке — решение за тобой и заказчиком.

## Чтобы работало постоянно

- Электропитание: «Сон → Никогда».
- Chrome и монитор должны быть запущены. После перезагрузки ПК — снова
  ярлыки 1 и 2 и вход в VFS.
- Автозапуск (необязательно): ярлык на `1-start-chrome.bat` в
  `shell:startup` (`Win+R` → `shell:startup`).

## Если что-то не так

| Симптом | Что делать |
|---|---|
| `403201` / пустая страница | Открыто не тем ярлыком, либо включён VPN. Только `1-start-chrome.bat`, без VPN. |
| «Не подключился к Chrome» | Chrome не запущен ярлыком 1 (нет порта 9222). Запусти ярлык 1. |
| В Telegram тишина | Заказчик не нажал `/start` боту, либо неверный `chat_id`. |
| `409 Repeated Delay` | Норма — лимит частоты, монитор сам ждёт. |
| `🔑 нажми Войти` | Сессия истекла (это норма каждые ~20–30 мин). Нажать «Войти» в открытом Chrome. |

## Границы

Монитор только читает доступность: **не бронирует, не вводит паролей, не
обходит капчу, не меняет IP**.
